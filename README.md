# CederusAI – Process Readiness Studio

A single-page workshop tool for mapping and scoring business processes for AI and automation readiness. Built with Vite, React, TypeScript, and TailwindCSS.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the dev server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Features
- Industry-specific process libraries that swap when the business type changes.
- Process portfolio with filtering, search, add, duplicate, and delete actions.
- Readiness scoring using weighted sliders and risk adjustment.
- Portfolio stats, impact/effort cues, and executive summary generator.
- Dark, compact UI styled with TailwindCSS.
